
JVM
Observation 1 : 

Some portion of bytecode is very critical - computer keeps on executing these bytecode instructions again and again repeatdly for most of its execution time. So, a JVM should convert bytecode for all such critical portions into the machine language form just once and use the already converted code next time.

Observation 2 : 

programmers may make silly mistakes in the program they write and because of that the programs run slower on any computer. So a JVM should optimize the bytecode before converting them into the machine language for a particular computer.
